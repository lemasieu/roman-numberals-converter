# Roman Numerals Converter

A simple, interactive web tool that converts between Arabic (natural) numbers and Roman numerals in real-time. Perfect for learning, quick reference, or everyday use.

## 🚀 Live Demo

Check out the live demo: [https://www.xn--msiu-goa8b.vn/github/roman-numberals-converter](https://www.xn--msiu-goa8b.vn/github/roman-numberals-converter)

## ✨ Features

- **Two-Way Conversion** – Convert Arabic numbers to Roman numerals and vice versa
- **Real-Time Updates** – See the conversion result instantly as you type
- **Clean Interface** – Minimal, user-friendly design with a clear layout
- **Responsive** – Works on desktop, tablet, and mobile devices

## 📝 How It Works

1. **Enter an Arabic number** – Type any natural number (e.g., 2024) into the "Số tự nhiên (Ả Rập)" field
2. **View the Roman numeral** – The corresponding Roman numeral (e.g., MMXXIV) appears instantly in the second field
3. **Enter a Roman numeral** – Type a valid Roman numeral (e.g., XIV) into the "Số La Mã" field
4. **View the Arabic number** – The corresponding Arabic number (e.g., 14) appears instantly in the first field
5. **Clear both fields** – Click the "Xóa" (Clear) button to reset both input fields

The conversion happens automatically as you type, with no need to press a submit button.
